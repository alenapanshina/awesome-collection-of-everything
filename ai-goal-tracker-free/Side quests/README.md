# Side Quests

**Definition:** Fun, enrichment, and wishlist items with no pressure or urgency. These are for joy.

## Key Characteristics
- No deadline required
- Purely optional — won't affect your core goals
- Can be picked up when you have energy/time/money
- Give yourself permission to enjoy these without guilt

## Examples
- Travel to a dream destination
- Learn a musical instrument
- Buy something you've been wanting
- Try a new hobby or sport
- Take a fun class

## File Format
Each side quest has its own `.md` file with:
- Status: Wishlist | Planning | Done
- Category: Travel | Learning | Shopping | Experience | Hobby
- Description
- Notes / Ideas

## Adding a Side Quest
1. Copy `_template.md` and rename with lowercase-hyphen naming (e.g., `learn-guitar.md`)
2. Fill in what you know
3. No pressure — these can sit here until you're ready
