# One-off Projects

**Definition:** Finite projects with a clear endpoint. Once done, they're done.

## Key Characteristics
- Have a defined "success" state (e.g., house renovated, book written)
- Require active planning & execution
- Can be completed and crossed off
- Track with milestones and WOOP

## Examples
- Renovate kitchen
- Write a book
- Plan a wedding
- Complete a certification

## File Format
Each project has its own `.md` file with:
- Status: Not started | In progress | Completed
- Category: Career | Health | Home | Finance | Personal
- Description
- Milestones / Next actions
- Notes

## Adding a New Project
1. Copy `_template.md` and rename with lowercase-hyphen naming (e.g., `renovate-kitchen.md`)
2. Fill in the template
3. Apply WOOP to identify internal obstacles
