# AI Goal Tracker (Free Version)

A simple system for tracking goals with AI assistance. Works with Claude, ChatGPT, Cursor, or any LLM.

## Quick Setup

### For Claude Projects
1. Create a new Project
2. Paste `Memory.md` into Project Instructions
3. Upload the folders to Project Knowledge

### For ChatGPT
1. Go to Custom Instructions or create a GPT
2. Paste `Memory.md` as the system prompt

### For Cursor or VS Code
1. Open this folder in your editor
2. Start chatting about your goals

### For Other AI Tools
1. Copy the contents of `Memory.md` into your AI's system prompt
2. Upload or reference the goal folders

## How It Works

Organize your goals into 3 types:

| Type | What It Is | Example |
|------|-----------|---------|
| **Pillars** | Ongoing habits (never "done") | Exercise, reading, side business |
| **One-off Projects** | Finite with clear endpoint | Renovate kitchen, write book |
| **Side Quests** | Fun wishlist items | Travel, hobbies, bucket list |
