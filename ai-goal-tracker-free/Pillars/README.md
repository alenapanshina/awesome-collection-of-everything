# Pillars

**Definition:** Ongoing areas of life you continuously maintain and grow. No endpoint — you never "complete" a pillar.

## Two Types of Pillars

### Work Pillars
Ongoing projects requiring regular time investment.
- Examples: side business, content creation, networking, skill development
- Need dedicated hours each week
- Progress = growth, not completion

### Habit Pillars
Recurring actions/routines you maintain.
- Examples: exercise routine, reading habit, meal prep, self-care
- Can become automatic over time (lower cognitive load)
- Progress = consistency, not completion

## File Format
Each pillar has its own `.md` file with:
- Status: Active | Paused
- Category: Business | Health | Self-care | Family | Social | Mindset
- Description
- Tracking (recurring checkboxes or notes)

## Adding a New Pillar
1. Copy `_template.md` and rename with lowercase-hyphen naming (e.g., `gym-routine.md`)
2. Fill in the template
3. Decide if it's a Work or Habit pillar for time budgeting
