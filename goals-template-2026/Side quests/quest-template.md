## 📊 Metrics (Indicators, Not Targets)
*Metrics are questions, not answers. Use them to learn, not to judge.*

**Guiding Principles:**
- Indicators reveal system health; targets create gaming.
- Ask "What is this telling us?" not "Did we hit the number?"
- Balance metrics: pair speed with quality, output with wellbeing.
- Make metrics temporary - discard when no longer useful.
